# Getting Started with GitHub Copilot

A hands-on GitHub Skills project designed to demonstrate how **GitHub Copilot** can assist developers throughout the software development workflow.

This project provides practical experience using GitHub Copilot to understand an existing codebase, plan changes, write and debug code, and review development work.

## About the Project

This repository is based on the **GitHub Skills – Getting Started with GitHub Copilot** exercise.

The main goal is to learn how to use GitHub Copilot as an AI-powered programming assistant during different stages of software development.

The exercise uses a sample **Mergington High School extracurricular activities website** as the application that is modified while learning Copilot workflows.

## What I Learned

Through this project, I learned how GitHub Copilot can be used to:

* Understand an unfamiliar codebase

* Generate and modify code

* Debug programming problems

GitHub's documentation also describes using Copilot to explore repositories, understand files, and explain specific sections of code.

## GitHub Copilot Workflow

```text
Understand
    ↓
Explore the Code
    ↓
Ask Copilot
    ↓
Create a Plan
    ↓
Implement Changes
    ↓
Test & Debug
    ↓
Review Changes
    ↓
Commit / Pull Request
```

This workflow demonstrates how an AI coding assistant can support multiple stages of development rather than only generating code.

## Development Environment

The project can be completed using a preconfigured GitHub Codespace and Visual Studio Code. The official exercise is designed to take less than one hour and requires basic coding knowledge and familiarity with VS Code.

### Prerequisites

* GitHub account
* GitHub Copilot access
* Basic programming knowledge
* Basic Git and GitHub knowledge
* Visual Studio Code familiarity

GitHub also provides a Copilot app workflow where a repository can be connected and used for AI-assisted development sessions.

### 3. Start the Development Environment

### 4. Use GitHub Copilot

Use Copilot to:

```text
Explain → Plan → Develop → Debug → Review
```

Ask questions about the source code and use Copilot's suggestions to understand and modify the application.

## Key Skills Demonstrated

### Code Generation

## Example Copilot Prompts

### Understand Code

```text
Explain what this file does and describe the main functions.
```

### Plan a Change

```text
Create a step-by-step plan for adding this feature.
```

### Implement a Feature

```text
Implement the planned changes and explain what was modified.
```

### Debug

```text
Find the cause of this error and suggest a fix.
```

### Review

```text
Review these changes and identify possible bugs or improvements.
```
